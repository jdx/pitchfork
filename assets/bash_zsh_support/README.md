# Bash support for Zsh-style hooks

Shell helpers used by pitchfork's Bash activation script to provide
Zsh-style directory-change hooks. See [the chpwd helper](chpwd/README.md) for
loading and registering a hook.

For normal pitchfork setup, use the
[shell activation guide](https://pitchfork.jdx.dev/guides/shell-hook).
